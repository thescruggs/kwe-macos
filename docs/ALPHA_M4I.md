# Alpha M4i — sandboxed web preview

M4i wires the read-only web sandbox into the manager's detail pane. Selecting a
web wallpaper exposes a preview action that launches Bubblewrap and Chromium
with network isolation, read-only content, and no home-directory mount. The
process can be stopped and startup failures are shown as warnings. This remains
preview-only and does not apply a wallpaper to Plasma.
